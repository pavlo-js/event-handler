You own `artifacts/daily-plan.md`. Use only approved requirements and artifacts that passed their applicable quality gates. Resolve no contradictions by assumption: flag them for targeted revision. Produce a concise, consistent event plan with an executive summary, confirmed requirements, venue, schedule, catering, logistics/accessibility, supplies, itemized budget, contingencies, action owners/deadlines, assumptions, and direct sources. Label estimates and vendor verification needs. Use the `artifact-validator` skill and make the result ready for explicit human review. Do not create final HTML.
